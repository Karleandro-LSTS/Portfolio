# Karleandro | Portfólio

Portfólio pessoal de Engenharia de Software com foco em **Python, automação, planilhas e dados**, além de projetos de robótica.

## Projetos em destaque

- **Automação de relatórios:** script que lê planilhas, calcula indicadores e gera relatórios automaticamente.
- **Coleta de dados da web:** extração de informações de sites para planilhas atualizadas.
- **Robótica e eletrônica:** braço robótico e sistemas com Arduino/ESP32.

## Tecnologias

Python, Pandas, Excel, Google Sheets, Arduino, ESP32, Git.

## Como ver o site

Este repositório publica o portfólio via **GitHub Pages**. Depois de subir os arquivos:

1. Vá em **Settings > Pages**.
2. Em *Source*, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. Aguarde alguns minutos. O site ficará em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
